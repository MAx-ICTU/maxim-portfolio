# Максим — личное портфолио

Сайт Junior 1С-разработчика из Кирова: текущая система управления сервисной компанией, веб-проекты, образование и служба, творческий раздел и контакты.

**Открыть сайт:** https://maxim-1c-portfolio.amandavaldez6216.chatgpt.site/

## Локальный запуск

Нужен установленный Node.js. Дополнительные библиотеки и сборка не требуются.

```sh
git clone https://github.com/MAx-ICTU/maxim-portfolio.git
cd maxim-portfolio
node preview.mjs
```

Откройте http://127.0.0.1:4173. После изменений обновите страницу в браузере. Остановка сервера — Ctrl+C.

## Структура

```text
dist/
  index.html       Главная страница, биография, проекты и контакты
  style.css        Оформление и адаптация для телефонов
  app.js           Анимация 1С, фильтры, карточки проектов, краткое резюме
  assets/          Обложки проектов и иконка сайта
preview.mjs        Локальный сервер для просмотра
.openai/
  hosting.json     Идентификатор и настройки существующего сайта в Sites
```

## Как дорабатывать

- **Тексты и контакты:** редактируйте `dist/index.html`.
- **Карточку для работодателя и подробности проектов:** редактируйте объект `dialogs` в `dist/app.js`. При изменении биографии и контактов обновляйте обе версии текста.
- **Цвета и шрифты:** основные настройки находятся в начале `dist/style.css`, в блоке `:root`.
- **Фотографии и обложки:** добавляйте файлы в `dist/assets/` и указывайте относительные ссылки в HTML.
- **Музыка и видео:** в `index.html` предусмотрен раздел `#creative`. Пока он явно сообщает, что работы будут добавлены позже. Замените заглушки реальными ссылками или медиаплеерами, когда материалы будут готовы.
- **Статус проектов:** обновляйте описание, статус и соответствующее содержимое карточек. Информация из GitHub не загружается автоматически.

## Проверка изменений

```sh
node --check dist/app.js
node preview.mjs
```

Перед публикацией откройте сайт на компьютере и в узком окне. Проверьте фильтры, карточки проектов, мобильное меню, телефон и почту. В карточке «Для работодателя» кнопка «Сохранить в PDF» открывает системное окно печати — выберите сохранение в PDF.

## Публикация

Рабочая версия размещена в **Sites**. GitHub хранит доступные для дальнейшей работы исходники. Изменения в репозитории **не публикуются в Sites автоматически**.

После правок можно попросить Codex: «Обнови мой существующий сайт в Sites из репозитория MAx-ICTU/maxim-portfolio, сохрани адрес и публичный доступ». Codex должен загрузить текущие исходники сайта через Sites, перенести проверенные изменения из GitHub и опубликовать новую версию. Идентификатор существующего сайта указан в `.openai/hosting.json`; создавать новый сайт не нужно.

Для самостоятельного переноса на другой статический хостинг достаточно содержимого `dist/`. Серверная часть, база данных и секретные ключи сайту не нужны.
